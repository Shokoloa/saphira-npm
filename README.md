# Saphira Bump API Wrapper

**Saphira Bump** est une librairie TypeScript / JavaScript pour interagir facilement avec l’API Saphira Bump.  
Elle permet de poster et récupérer les statistiques d’une application, vérifier les votes/bump des utilisateurs, et gérer les guildes.

---

## ⚡ Installation

```bash
# NPM
npm install saphira-bump

# Yarn
yarn add saphira-bump
